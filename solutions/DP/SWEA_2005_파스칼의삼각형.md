# SWEA 2005 🔺 파스칼의 삼각형 (Java)

## 느낀점
-어렵지 않게 풀었다.
-이전 행의 두 값을 더해 다음 행 계산

## 흐름

1. 테스트케이스 개수 `T`와 각 테스트케이스의 삼각형 크기 `N`을 입력받는다.
2. `N x N` 배열을 만들고 첫 번째 칸 `arr[0][0]`을 `1`로 초기화한다.
3. 두 번째 행부터 각 행의 첫 번째 칸과 마지막 칸을 `1`로 설정한다.
4. 가운데 칸은 바로 위 행의 왼쪽 칸과 같은 열의 칸을 더해 채운다.
   - `arr[i][j] = arr[i - 1][j - 1] + arr[i - 1][j]`
5. 테스트케이스 번호를 출력한 뒤, 각 행에서 열 인덱스 `0`부터 `i`까지 출력한다.

## 작성 코드

```java
import java.util.Scanner;

class Solution
{
    public static void main(String args[]) throws Exception
    {
        Scanner sc = new Scanner(System.in);
        int T;
        T=sc.nextInt();

        for(int test_case = 1; test_case <= T; test_case++)
        {
            int N = sc.nextInt();

            int[][] arr = new int[N][N];
            arr[0][0] = 1;
            for(int i = 1; i <= N-1; i++) {
                arr[i][0]=1;
                arr[i][i]=1;
                for(int j = 1 ; j < i; j++) {
                    arr[i][j] = arr[i-1][j-1] + arr[i-1][j];
                }
            }

            System.out.println("#" + test_case);
            for(int i = 0 ; i < N; i++) {
                for(int j = 0 ; j <= i; j++) {
                    System.out.print(arr[i][j]+ " ");
                }
                System.out.println();
            }
        }
    }
}
```

## AI 코드 리뷰

### 개선할 점

- `arr`를 `triangle`, `N`을 `size`로 바꾸면 변수의 의미를 더 쉽게 파악할 수 있다.
- `i <= N - 1`은 `i < N`으로 표현해 반복 범위를 간결하게 쓸 수 있다.
- 첫 번째 행도 반복문에서 양끝을 `1`로 설정하면 `arr[0][0] = 1`을 별도로 작성하지 않아도 된다.
- `StringBuilder`로 출력을 모으고, 숫자 사이에만 공백을 넣으면 행 끝의 불필요한 공백을 없앨 수 있다.
- 아래 개선 코드도 시간 복잡도와 공간 복잡도는 각각 `O(N²)`이다.

### AI 개선 코드

```java
import java.util.Scanner;

class Solution {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int testCount = sc.nextInt();

        for (int testCase = 1; testCase <= testCount; testCase++) {
            int size = sc.nextInt();
            int[][] triangle = new int[size][size];

            for (int row = 0; row < size; row++) {
                triangle[row][0] = 1;
                triangle[row][row] = 1;

                for (int col = 1; col < row; col++) {
                    triangle[row][col] = triangle[row - 1][col - 1]
                            + triangle[row - 1][col];
                }
            }

            StringBuilder output = new StringBuilder();
            output.append("#").append(testCase).append('\n');

            for (int row = 0; row < size; row++) {
                for (int col = 0; col <= row; col++) {
                    if (col > 0) {
                        output.append(' ');
                    }
                    output.append(triangle[row][col]);
                }
                output.append('\n');
            }

            System.out.print(output);
        }
    }
}
```
