# SWEA 1289 💾 원재의 메모리 복구하기 (Java)

## 느낀점
- easy

## 흐름

1. 테스트케이스 개수 `T`를 입력받는다.
2. 원래 메모리를 문자열로 입력받고 문자 배열로 변환한다.
3. 첫 번째 비트가 `1`이면 `count`를 `1`로 설정한다.
4. 두 번째 비트부터 이전 비트와 비교한다.
5. 값이 다르면 `count`를 증가시킨다.
6. 테스트케이스 번호와 최소 수정 횟수를 출력한다.

## 작성 코드

기본 안내 주석과 사용하지 않는 `FileInputStream` import를 제외한 작성 코드이다.

```java
import java.util.Scanner;

class Solution
{
    public static void main(String args[]) throws Exception
    {
        Scanner sc = new Scanner(System.in);
        int T;
        T=sc.nextInt();

        for(int test_case = 1; test_case <= T; test_case++)
        {
            int count = 0;
            String memory = sc.next();
            char[] arr = memory.toCharArray();

            for(int i = 0; i < arr.length; i++) {
                arr[i] = memory.charAt(i);
            }

            if(arr[0] == '1') {
                count = 1;
            }
            for(int i = 1 ; i < arr.length; i++) {
                if(arr[i] != arr[i-1]) {
                    count += 1;
                }
            }

            System.out.println("#" + test_case + " " + count);
        }
    }
}
```

## AI 코드 리뷰

### 개선할 점

- `memory.toCharArray()`가 이미 각 문자를 배열에 복사하므로, 바로 뒤에서 `memory.charAt(i)`를 다시 대입하는 반복문은 제거할 수 있다.
- 문자 배열 없이 `memory.charAt(i)`로 직접 비교할 수도 있다.
- 현재 코드는 문자열 길이를 `L`이라고 할 때 시간 복잡도가 `O(L)`, 문자 배열에 사용하는 추가 공간이 `O(L)`이다.
- 아래 개선 코드는 초기 상태를 나타내는 `current = '0'`을 사용해 첫 비트도 같은 반복문에서 처리한다. 시간 복잡도는 `O(L)`, 입력 문자열을 제외한 추가 공간은 `O(1)`이다.

### AI 개선 코드

```java
import java.util.Scanner;

class Solution {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int testCount = sc.nextInt();

        for (int testCase = 1; testCase <= testCount; testCase++) {
            String memory = sc.next();
            int count = 0;
            char current = '0';

            for (int i = 0; i < memory.length(); i++) {
                char target = memory.charAt(i);

                if (target != current) {
                    count++;
                    current = target;
                }
            }

            System.out.println("#" + testCase + " " + count);
        }
    }
}
```
