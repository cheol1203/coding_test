# SWEA 1240 🔐 단순 2진 암호코드 (Java)

## 느낀점
- String을 char 배열로 바꿀때는 .toCharArray, char 배열을 다시 String으로 바꿀때는 new String(char배열)
- 오른쪽 끝 1에서 56비트 추출, Map으로 숫자 변환 후 검증

## 흐름

1. 테스트케이스 개수 `T`와 배열 크기 `N`, `M`을 입력받는다.
2. 숫자 `0~9`에 해당하는 7자리 이진 문자열을 `Map<String, Integer>`에 저장한다.
3. 각 줄을 문자 배열로 입력받아 `char[][]`에 저장한다.
4. 각 행을 오른쪽에서 왼쪽으로 탐색하며 처음 발견한 `1`을 암호의 끝 위치로 잡는다.
   - 등록된 숫자 패턴은 모두 `1`로 끝나므로 오른쪽 끝의 `1`을 기준으로 찾을 수 있다.
5. 암호는 7비트 숫자 8개로 이루어져 있으므로, 끝 위치 `j`에서 `55`를 뺀 위치부터 56비트를 읽는다.
6. 7비트씩 문자열로 만들어 Map에서 숫자를 찾고, `code` 배열에 순서대로 저장한다.
7. 암호를 찾으면 `exit`으로 탐색을 종료한다.
8. 홀수 번째 숫자의 합에 `3`을 곱하고 짝수 번째 숫자의 합을 더한다.
   - 배열 인덱스는 `0`부터 시작하므로 `i % 2 == 0`이 홀수 번째 숫자에 해당한다.
9. 검증 합이 `10`의 배수이면 숫자 8개의 합을 출력하고, 그렇지 않으면 `0`을 출력한다.

## 작성 코드

기본 안내 주석과 주석 처리된 파일 입력 예시를 제외한 작성 코드이다.

```java
import java.util.HashMap;
import java.util.Map;
import java.util.Scanner;
import java.io.FileInputStream;

class Solution
{
    public static void main(String args[]) throws Exception
    {
        Scanner sc = new Scanner(System.in);
        int T;
        T=sc.nextInt();

        for(int test_case = 1; test_case <= T; test_case++)
        {
            int N = sc.nextInt();
            int M = sc.nextInt();

            char[][] arr = new char[N][M];
            Map<String,Integer> map = new HashMap<>();
            map.put("0001101", 0);
            map.put("0011001", 1);
            map.put("0010011", 2);
            map.put("0111101", 3);
            map.put("0100011", 4);
            map.put("0110001", 5);
            map.put("0101111", 6);
            map.put("0111011", 7);
            map.put("0110111", 8);
            map.put("0001011", 9);

            for(int i = 0; i < N; i++) {
                arr[i] = sc.next().toCharArray();
            }

            Integer[] code = new Integer[8];
            boolean exit = false;

            for(int i = 0 ; i< N; i++) {
                if(exit) {
                    break;
                }
                for(int j = M-1; j >=0; j--) {
                    if(exit) {
                        break;
                    }
                    if(arr[i][j]=='1') {
                        for(int k = j-55, a=0 ; a < code.length; a++) {
                            char[] charCode = new char[7];
                            for(int w = 0; w < 7; w++) {
                                charCode[w] = arr[i][k];
                                k++;
                            }
                            code[a] = map.get(new String(charCode));
                        }
                        exit = true;
                    }
                }
            }

            int sum = 0;
            for(int i = 0 ; i< code.length; i++) {
                if(i%2==0) {
                    sum+= 3 * code[i];
                }else {
                    sum+= code[i];
                }
            }

            if(sum%10==0) {
                int total = 0 ;
                for(int i = 0 ; i<code.length; i++) {
                    total += code[i];
                }
                System.out.println("#" + test_case + " " + total);
            }else {
                System.out.println("#" + test_case + " 0");
            }
        }
    }
}
```

## AI 코드 리뷰

### 개선할 점

- 숫자 패턴은 모든 테스트케이스에서 같으므로 Map을 테스트케이스 반복문 밖에서 한 번만 만들 수 있다.
- 숫자를 저장하는 배열은 `Integer[]` 대신 `int[]`을 사용할 수 있다. Map에 없는 패턴을 조회하면 `null`이 반환되므로, 입력 조건을 벗어난 데이터까지 처리하려면 숫자 변환 전에 별도로 확인해야 한다.
- 암호가 있는 한 행만 있으면 계산할 수 있으므로 전체 `char[][]`를 저장하지 않아도 된다. 다만 다음 테스트케이스의 입력이 섞이지 않도록 나머지 행도 끝까지 읽어야 한다.
- 문자열의 `lastIndexOf('1')`로 끝 위치를 찾고, `substring()`으로 7비트씩 잘라 읽으면 직접 문자 배열을 만드는 중첩 반복문을 줄일 수 있다.
- `55`, `7`, `8`은 각각 전체 암호 길이, 숫자당 비트 수, 숫자 개수와 연결되어 있다. 상수로 이름을 붙이면 `끝 위치 - 전체 길이 + 1`이라는 시작점 계산이 더 명확해진다.
- 검증 합과 숫자의 총합은 같은 반복문에서 함께 계산할 수 있다.
- 현재 코드는 입력·탐색에 `O(NM)` 시간과 배열 저장에 `O(NM)` 공간을 사용한다. 아래 개선 코드는 시간 복잡도는 `O(NM)`으로 유지하고, 행 문자열 저장 공간을 `O(M)`으로 줄인다. 암호 길이는 56비트로 고정되어 있다.
- 사용하지 않는 `FileInputStream` import는 개선 코드에서 제거했다.

### AI 개선 코드

```java
import java.util.HashMap;
import java.util.Map;
import java.util.Scanner;

class Solution {
    static final int BITS_PER_DIGIT = 7;
    static final int DIGIT_COUNT = 8;
    static final int CODE_LENGTH = BITS_PER_DIGIT * DIGIT_COUNT;

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        Map<String, Integer> digits = new HashMap<>();
        String[] patterns = {
            "0001101", "0011001", "0010011", "0111101", "0100011",
            "0110001", "0101111", "0111011", "0110111", "0001011"
        };

        for (int digit = 0; digit < patterns.length; digit++) {
            digits.put(patterns[digit], digit);
        }

        int testCount = sc.nextInt();

        for (int testCase = 1; testCase <= testCount; testCase++) {
            int rows = sc.nextInt();
            int cols = sc.nextInt();
            String encoded = null;

            for (int row = 0; row < rows; row++) {
                String line = sc.next();

                if (encoded == null) {
                    int end = line.lastIndexOf('1');

                    if (end >= CODE_LENGTH - 1) {
                        encoded = line.substring(end - CODE_LENGTH + 1, end + 1);
                    }
                }
            }

            int checksum = 0;
            int total = 0;
            boolean valid = encoded != null;

            if (valid) {
                for (int index = 0; index < DIGIT_COUNT; index++) {
                    int start = index * BITS_PER_DIGIT;
                    String pattern = encoded.substring(start, start + BITS_PER_DIGIT);
                    Integer digit = digits.get(pattern);

                    if (digit == null) {
                        valid = false;
                        break;
                    }

                    total += digit;
                    checksum += digit * (index % 2 == 0 ? 3 : 1);
                }
            }

            int answer = valid && checksum % 10 == 0 ? total : 0;
            System.out.println("#" + testCase + " " + answer);
        }
    }
}
```
