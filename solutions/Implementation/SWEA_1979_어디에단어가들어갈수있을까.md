# SWEA 1979 🧩 어디에 단어가 들어갈 수 있을까 (Java)

## 느낀점

- 가로·세로에서 연속된 1의 길이가 정확히 K인 구간을 세고, 줄 끝에 남은 구간도 별도로 확인한다.
- 0을 만나면 조건을 추가하는 부분에서 AI로부터 힌트를 받았다.

## 흐름

1. 테스트케이스 개수 `T`, 퍼즐 크기 `N`, 단어 길이 `K`를 입력받는다.
2. 퍼즐 정보를 `int[N][N]` 배열에 저장한다.
3. 각 행에서 `oneCount = 0`으로 시작해 가로 방향을 검사한다.
4. `1`을 만나면 `oneCount`를 증가시킨다.
5. `0`을 만나면 끝난 구간의 길이가 `K`인지 확인해 정답을 증가시키고, `oneCount = 0`으로 초기화한다.
6. 한 행의 반복문이 끝난 뒤에도 `oneCount == K`인지 확인해 오른쪽 끝까지 이어진 구간을 센다.
7. `arr[j][i]`로 각 열을 읽으며 같은 방식으로 세로 방향을 검사한다. 아래쪽 끝까지 이어진 구간도 별도로 확인한다.
8. 가로·세로에서 찾은 자리 수를 테스트케이스 번호와 함께 출력한다.

## 작성 코드

기본 안내 주석과 주석 처리된 파일 입력 예시를 제외한 작성 코드이다.

```java
import java.util.Scanner;

class Solution
{
    public static void main(String args[]) throws Exception
    {
        Scanner sc = new Scanner(System.in);
        int T;
        T=sc.nextInt();

        for(int test_case = 1; test_case <= T; test_case++)
        {
            int N = sc.nextInt();
            int K = sc.nextInt();
            int[][] arr = new int[N][N];
            for(int i = 0 ; i<N; i++) {
                for(int j = 0 ; j<N; j++) {
                    arr[i][j] = sc.nextInt();
                }
            }

            int count = 0;
            for(int i = 0 ; i<N; i++) {
                int oneCount = 0;
                for(int j = 0 ; j < N; j++) {
                    if(arr[i][j]==1) {
                        oneCount++;
                    }else {
                        if(oneCount==K) {
                            count++;
                        }
                        oneCount=0;
                    }
                }
                if(oneCount==K) {
                    count++;
                }
            }
            for(int i = 0 ; i < N; i++) {
                int oneCount = 0;
                for(int j = 0 ; j < N; j++) {
                    if(arr[j][i]==1) {
                        oneCount++;
                    }else {
                        if(oneCount==K) {
                            count++;
                        }
                        oneCount=0;
                    }
                }
                if(oneCount==K) {
                    count++;
                }
            }
            System.out.println("#" + test_case + " " + count);
        }
    }
}
```

## AI 코드 리뷰

### 개선할 점

- 구간이 끝난 시점에 `oneCount == K`를 확인하므로 `K`보다 긴 구간을 제외할 수 있다. 구간 중간에 개수가 `K`에 도달하자마자 정답을 증가시키면 긴 구간도 잘못 셀 수 있다.
- `0`에서 끝나는 구간뿐 아니라 행·열의 마지막 칸에서 끝나는 구간도 처리한 점이 적절하다.
- 가로와 세로는 순회 구조가 같으므로 하나의 이중 반복문에서 `rowCount`, `colCount`를 각각 관리할 수 있다. 아래 개선 코드는 이 방식으로 중복된 바깥 반복문을 줄였다.
- `arr`는 `board`, `count`는 `answer`, `N`과 `K`는 `size`와 `wordLength`로 바꾸면 의미가 더 명확해진다.
- 작성 코드와 개선 코드 모두 시간 복잡도와 공간 복잡도는 각각 `O(N²)`이다. 개선 코드는 알고리즘의 복잡도를 바꾸기보다 반복 구조를 정리한 예시이다.

### AI 개선 코드

```java
import java.util.Scanner;

class Solution {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int testCount = sc.nextInt();

        for (int testCase = 1; testCase <= testCount; testCase++) {
            int size = sc.nextInt();
            int wordLength = sc.nextInt();
            int[][] board = new int[size][size];

            for (int row = 0; row < size; row++) {
                for (int col = 0; col < size; col++) {
                    board[row][col] = sc.nextInt();
                }
            }

            int answer = 0;

            for (int i = 0; i < size; i++) {
                int rowCount = 0;
                int colCount = 0;

                for (int j = 0; j < size; j++) {
                    if (board[i][j] == 1) {
                        rowCount++;
                    } else {
                        if (rowCount == wordLength) {
                            answer++;
                        }
                        rowCount = 0;
                    }

                    if (board[j][i] == 1) {
                        colCount++;
                    } else {
                        if (colCount == wordLength) {
                            answer++;
                        }
                        colCount = 0;
                    }
                }

                if (rowCount == wordLength) {
                    answer++;
                }
                if (colCount == wordLength) {
                    answer++;
                }
            }

            System.out.println("#" + testCase + " " + answer);
        }
    }
}
```
