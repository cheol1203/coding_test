# SWEA 11315 ⚫ 오목 판정 (Java)

## 느낀점
- 가로·세로·양쪽 대각선 검사, 문자열 입력과 문자 비교 복습

## 흐름

1. 테스트케이스 개수 `T`와 판의 크기 `N`을 입력받는다.
2. 각 줄을 문자열로 읽고 `charAt()`으로 한 글자씩 `char[][]`에 저장한다.
3. 가로 방향으로 각 행을 순회하며 연속된 돌의 개수를 센다.
4. 세로 방향으로 각 열을 순회하며 연속된 돌의 개수를 센다.
5. 돌이 있는 각 칸에서 오른쪽 아래와 왼쪽 아래 대각선을 각각 검사한다.
6. 빈칸을 만나면 `count = 0`으로 초기화하고, `count == 5`이면 `result = true`로 설정한다.
7. 한 방향의 검사가 끝났을 때 오목을 찾았다면 `YES`를 출력하고 다음 테스트케이스로 넘어간다.
8. 모든 방향에서 오목을 찾지 못했다면 `NO`를 출력한다.

## 작성 코드

```java
import java.util.Scanner;
import java.io.FileInputStream;

class Solution
{
    public static void main(String args[]) throws Exception
    {
        Scanner sc = new Scanner(System.in);
        int T;
        T=sc.nextInt();

        for(int test_case = 1; test_case <= T; test_case++)
        {
            int N = sc.nextInt();
            char[][] arr = new char[N][N];
            for(int i = 0 ; i < N; i++) {
                String str = sc.next();
                for(int j = 0; j < N; j++) {
                    arr[i][j] = str.charAt(j);
                }
            }

            boolean result = false;
            // 가로 체크
            for(int i = 0; i< N; i++) {
                int count = 0;
                for(int j = 0 ; j < N; j++) {
                    if(arr[i][j] == 'o') {
                        count++;
                    }else {
                        count = 0;
                    }
                    if(count==5) {
                        result = true;
                    }
                }
            }
            if(result) {
                System.out.println("#" + test_case + " YES");
                continue;
            }
            //세로 체크
            for(int i = 0; i< N; i++) {
                int count = 0;
                for(int j = 0 ; j < N; j++) {
                    if(arr[j][i] == 'o') {
                        count++;
                    }else {
                        count = 0;
                    }
                    if(count==5) {
                        result = true;
                    }
                }
            }
            if(result) {
                System.out.println("#" + test_case + " YES");
                continue;
            }
            //왼쪽에서 오른쪽으로 내려가는 대각 체크
            for(int i = 0; i< N; i++) {
                for(int j = 0 ; j < N; j++) {
                    int count = 0;
                    if(arr[i][j] == 'o') {
                        for(int k = i, w = j ; k < N & w < N; k++,w++) {
                            if(arr[k][w] == 'o') {
                                count++;
                            }else {
                                count = 0;
                            }
                            if(count == 5) {
                                result = true;
                            }
                        }
                    }
                }
            }
            if(result) {
                System.out.println("#" + test_case + " YES");
                continue;
            }
            //오른쪽에서 왼쪽으로 내려가는 대각 체크
            for(int i = 0; i< N; i++) {
                for(int j = 0 ; j < N; j++) {
                    int count = 0;
                    if(arr[i][j] == 'o') {
                        for(int k = i, w = j ; k < N & w >=0; k++,w--) {
                            if(arr[k][w] == 'o') {
                                count++;
                            }else {
                                count = 0;
                            }
                            if(count == 5) {
                                result = true;
                            }
                        }
                    }
                }
            }
            if(result) {
                System.out.println("#" + test_case + " YES");
                continue;
            }else {
                System.out.println("#" + test_case + " NO");
            }
        }
    }
}
```

## AI 코드 리뷰

### 개선할 점

- 입력은 한 줄이 하나의 문자열이므로, 처음 시도했던 칸마다 `sc.next()`를 호출하는 방식 대신 마지막 코드처럼 한 줄을 읽고 문자로 나누어야 한다.
- 처음 시도한 `String.equals('o')`는 문자열과 문자를 비교하므로 `false`가 된다. 마지막 코드의 `char`와 `'o'`를 `==`로 비교하는 방식이 적절하다.
- `sc.next()`는 앞의 공백과 줄바꿈을 건너뛰므로, `nextInt()` 다음에 `nextLine()`을 따로 호출할 필요가 없다.
- 대각선 반복 조건의 `&`도 현재 코드에서는 동작하지만, 논리 조건에는 왼쪽이 `false`일 때 오른쪽 평가를 생략하는 `&&`를 사용할 수 있다.
- 가로·세로·양쪽 대각선을 방향 배열로 묶으면 네 방향의 비슷한 코드를 줄일 수 있다.
- 현재 대각선 검사는 각 칸에서 대각선 끝까지 반복 탐색하므로 전체 시간 복잡도가 최악의 경우 `O(N³)`이다. 각 시작점에서 방향별로 다섯 칸만 검사하면 `O(N²)`으로 줄일 수 있다.
- 검사 로직을 메서드로 분리하면 오목을 찾는 즉시 `true`를 반환하고, 출력도 한 곳에서 처리할 수 있다.
- 다섯 개 이상 연속한 돌에는 연속된 다섯 칸이 반드시 포함되므로, 다섯 칸을 검사하는 방식으로도 판정할 수 있다.
- 사용하지 않는 `FileInputStream` import와 기본 안내 주석은 개선 코드에서 제거했다. 작성 코드는 기본 안내 주석을 제외하고 마지막에 보내준 풀이를 유지했다.

### AI 개선 코드

```java
import java.util.Scanner;

class Solution {
    // 오른쪽, 아래, 오른쪽 아래, 왼쪽 아래
    static final int[] DR = {0, 1, 1, 1};
    static final int[] DC = {1, 0, 1, -1};

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int testCount = sc.nextInt();

        for (int testCase = 1; testCase <= testCount; testCase++) {
            int size = sc.nextInt();
            char[][] board = new char[size][];

            for (int row = 0; row < size; row++) {
                board[row] = sc.next().toCharArray();
            }

            String answer = hasOmok(board) ? "YES" : "NO";
            System.out.println("#" + testCase + " " + answer);
        }
    }

    static boolean hasOmok(char[][] board) {
        int size = board.length;

        for (int row = 0; row < size; row++) {
            for (int col = 0; col < size; col++) {
                if (board[row][col] != 'o') {
                    continue;
                }

                for (int direction = 0; direction < 4; direction++) {
                    int count = 0;

                    for (int step = 0; step < 5; step++) {
                        int nextRow = row + DR[direction] * step;
                        int nextCol = col + DC[direction] * step;

                        if (nextRow < 0 || nextRow >= size
                                || nextCol < 0 || nextCol >= size) {
                            break;
                        }
                        if (board[nextRow][nextCol] != 'o') {
                            break;
                        }
                        count++;
                    }

                    if (count == 5) {
                        return true;
                    }
                }
            }
        }

        return false;
    }
}
```
