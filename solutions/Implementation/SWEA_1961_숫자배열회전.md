# SWEA 1961 🔄 숫자 배열 회전 (Java)

## 느낀점

- 90도 회전의 인덱스 규칙을 반복 적용해 180도·270도 결과를 만들고, 각 회전 결과를 행별로 나란히 출력한다.
- 규칙을 찾는것이 중요!!

## 흐름

1. 테스트케이스 개수 `T`, 배열 크기 `N`, 원본 배열 `arr`를 입력받는다.
2. 90도·180도·270도 회전 결과를 저장할 배열을 각각 만든다.
3. `result90[i][j] = arr[N - 1 - j][i]`로 시계 방향 90도 회전 결과를 계산한다.
4. 같은 규칙을 `result90`에 적용해 `result180`을 만들고, 다시 `result180`에 적용해 `result270`을 만든다.
5. 각 회전 결과의 한 행을 `StringBuilder`로 이어 붙여 `result[i][0~2]`에 저장한다.
6. 테스트케이스 번호를 출력한 뒤, 같은 행의 90도·180도·270도 결과를 공백으로 구분해 출력한다.

## 작성 코드

기본 안내 주석과 주석 처리된 파일 입력 예시를 제외한 작성 코드이다.

```java
import java.util.Scanner;

class Solution
{
    public static void main(String args[]) throws Exception
    {
        Scanner sc = new Scanner(System.in);
        int T;
        T=sc.nextInt();

        for(int test_case = 1; test_case <= T; test_case++)
        {
            int N = sc.nextInt();
            int[][] arr = new int[N][N];
            String[][] result = new String[N][3];
            for(int i = 0 ; i< N; i++) {
                for(int j = 0; j < N; j++) {
                    arr[i][j] = sc.nextInt();
                }
            }
            int[][] result90= new int[N][N];
            int[][] result180= new int[N][N];
            int[][] result270= new int[N][N];
            for(int i = 0 ; i< N; i++) {
                for(int j = 0 ; j < N; j++) {
                    result90[i][j] = arr[N-1-j][i];
                }
            }
            for(int i = 0 ; i< N; i++) {
                for(int j = 0 ; j < N; j++) {
                    result180[i][j] = result90[N-1-j][i];
                }
            }
            for(int i = 0 ; i< N; i++) {
                for(int j = 0 ; j < N; j++) {
                    result270[i][j] = result180[N-1-j][i];
                }
            }

            for(int i = 0; i < N; i++) {
                StringBuilder sb = new StringBuilder();
                for(int j = 0; j < N; j++) {
                    sb.append(result90[i][j]);
                }
                result[i][0]= sb.toString();
            }
            for(int i = 0; i < N; i++) {
                StringBuilder sb = new StringBuilder();
                for(int j = 0; j < N; j++) {
                    sb.append(result180[i][j]);
                }
                result[i][1]= sb.toString();
            }
            for(int i = 0; i < N; i++) {
                StringBuilder sb = new StringBuilder();
                for(int j = 0; j < N; j++) {
                    sb.append(result270[i][j]);
                }
                result[i][2]= sb.toString();
            }
            System.out.println("#" + test_case);
            for(int i=0; i<N; i++) {
                for(int j = 0; j<3; j++) {
                    System.out.print(result[i][j]+ " ");
                }
                System.out.println();
            }
        }
    }
}
```

## AI 코드 리뷰

### 개선할 점

- `회전 결과[row][col] = 원본[N - 1 - col][row]`는 결과 위치를 기준으로 원본의 값을 가져오는 식이다. 원본 위치를 기준으로 쓰는 `회전 결과[col][N - 1 - row] = 원본[row][col]`과 같은 시계 방향 90도 회전을 나타낸다.
- 같은 회전 로직이 세 번 반복되므로 `rotate()` 메서드로 분리하면 중복을 줄일 수 있다.
- 출력할 때 각 회전 배열의 행을 직접 읽으면 중간 문자열 배열 `result`를 생략할 수 있다.
- 숫자는 한 행 안에서 붙여 쓰고, 서로 다른 각도의 결과 사이에만 공백을 넣도록 구성하면 행 끝의 불필요한 공백도 없앨 수 있다.
- `arr`를 `original`, 인덱스 `i`, `j`를 `row`, `col`로 바꾸면 좌표의 의미를 읽기 쉽다.
- 작성 코드와 개선 코드 모두 회전을 세 번 수행하므로 시간 복잡도는 `O(N²)`이며, 회전 결과 배열을 포함한 공간 복잡도도 `O(N²)`이다.

### AI 개선 코드

```java
import java.util.Scanner;

class Solution {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int testCount = sc.nextInt();

        for (int testCase = 1; testCase <= testCount; testCase++) {
            int size = sc.nextInt();
            int[][] original = new int[size][size];

            for (int row = 0; row < size; row++) {
                for (int col = 0; col < size; col++) {
                    original[row][col] = sc.nextInt();
                }
            }

            int[][] rotated90 = rotate(original);
            int[][] rotated180 = rotate(rotated90);
            int[][] rotated270 = rotate(rotated180);

            System.out.println("#" + testCase);

            for (int row = 0; row < size; row++) {
                StringBuilder output = new StringBuilder();

                for (int col = 0; col < size; col++) {
                    output.append(rotated90[row][col]);
                }
                output.append(' ');

                for (int col = 0; col < size; col++) {
                    output.append(rotated180[row][col]);
                }
                output.append(' ');

                for (int col = 0; col < size; col++) {
                    output.append(rotated270[row][col]);
                }

                System.out.println(output);
            }
        }
    }

    static int[][] rotate(int[][] original) {
        int size = original.length;
        int[][] rotated = new int[size][size];

        for (int row = 0; row < size; row++) {
            for (int col = 0; col < size; col++) {
                rotated[row][col] = original[size - 1 - col][row];
            }
        }

        return rotated;
    }
}
```
