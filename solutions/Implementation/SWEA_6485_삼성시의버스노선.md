# SWEA 6485 🚌 삼성시의 버스 노선 (Java)

## 느낀점

- 각 노선의 시작·끝 정류장을 포함해 통과 횟수를 누적하고, 요청받은 정류장 순서대로 결과를 출력
- 카운터 배열 선언해서 해결 , 쉬웠음

## 흐름

1. 테스트케이스 개수 `T`와 버스 노선 개수 `N`을 입력받는다.
2. 각 노선의 시작·끝 정류장을 `int[N][2]` 배열 `arr`에 저장한다.
3. 조회할 정류장 개수 `P`와 정류장 번호들을 배열 `C`에 저장한다.
4. 정류장 번호를 인덱스로 사용하는 `count` 배열을 만든다.
5. 각 노선의 시작 정류장부터 끝 정류장까지 순회하며 `count[j]`를 증가시킨다.
   - 양끝을 모두 포함하기 위해 `j <= arr[i][1]`을 사용한다.
6. 여러 노선이 겹치는 정류장은 통과 횟수가 누적되고, 지나가는 노선이 없으면 초기값 `0`이 유지된다.
7. `StringBuilder`에 테스트케이스 번호와 `count[C[i]]`를 조회 순서대로 추가해 출력한다.

## 작성 코드

기본 안내 주석과 주석 처리된 파일 입력 예시를 제외한 작성 코드이다.

```java
import java.util.Scanner;

class Solution
{
    public static void main(String args[]) throws Exception
    {
        Scanner sc = new Scanner(System.in);
        int T;
        T=sc.nextInt();

        for(int test_case = 1; test_case <= T; test_case++)
        {
            int N = sc.nextInt(); //버스 노선 개수
            int[][] arr = new int[N][2];
            for(int i = 0; i< N; i++) {
                for(int j = 0 ; j < 2 ; j++) {
                    arr[i][j] = sc.nextInt();
                }
            }
            int P = sc.nextInt();
            int[] C = new int[P];
            for(int i = 0; i<P; i++) {
                C[i]=sc.nextInt();
            }
            int[] count = new int[5001];
            for(int i = 0; i< N; i++) {
                for(int j = arr[i][0]; j <= arr[i][1]; j++) {
                    count[j]++;
                }
            }
            StringBuilder sb = new StringBuilder();
            sb.append("#").append(test_case);
            for(int i = 0 ; i< C.length; i++) {
                sb.append(" ").append(count[C[i]]);
            }
            System.out.println(sb);
        }
    }
}
```

## AI 코드 리뷰

### 개선할 점

- 노선의 시작과 끝을 입력받는 즉시 `count`에 누적하면 노선 정보 배열 `arr`를 생략할 수 있다.
- 조회할 정류장 번호도 입력받는 즉시 `count`에서 값을 꺼내 출력 문자열에 추가하면 `C` 배열이 필요 없다. 입력 순서와 출력 순서가 같으므로 전체 조회 목록을 따로 저장하지 않아도 된다.
- 정류장 번호가 `1~5000`이므로 크기 `5001`인 배열을 사용해 번호를 그대로 인덱스로 쓸 수 있다. `MAX_STOP` 상수로 최댓값을 표현하면 배열 크기의 의미가 명확해진다.
- `N`은 `routeCount`, `P`는 `queryCount`, 구간의 양끝은 `start`, `end`로 이름을 붙이면 역할을 읽기 쉽다.
- 각 테스트케이스 안에서 `count`와 출력 문자열을 새로 생성하므로 이전 테스트케이스의 값이 남지 않는다.
- 정류장 번호의 최댓값을 `R`이라 하면, 작성 코드와 개선 코드의 최악 시간 복잡도는 `O(NR + P)`이다. 출력 문자열을 제외한 추가 공간은 작성 코드의 `O(N + P + R)`에서 개선 코드의 `O(R)`로 줄어든다.

### AI 개선 코드

```java
import java.util.Scanner;

class Solution {
    static final int MAX_STOP = 5000;

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int testCount = sc.nextInt();

        for (int testCase = 1; testCase <= testCount; testCase++) {
            int routeCount = sc.nextInt();
            int[] count = new int[MAX_STOP + 1];

            for (int route = 0; route < routeCount; route++) {
                int start = sc.nextInt();
                int end = sc.nextInt();

                for (int stop = start; stop <= end; stop++) {
                    count[stop]++;
                }
            }

            int queryCount = sc.nextInt();
            StringBuilder output = new StringBuilder();
            output.append("#").append(testCase);

            for (int query = 0; query < queryCount; query++) {
                int stop = sc.nextInt();
                output.append(' ').append(count[stop]);
            }

            System.out.println(output);
        }
    }
}
```
