# SWEA 3499 🃏 퍼펙트 셔플 (Java)

## 느낀점
- 두 묶음으로 나누어 교대로 배치, 홀수 카드 수 처리

## 흐름

1. 테스트케이스 개수 `T`와 카드 수 `N`을 입력받는다.
2. 카드 이름을 입력 순서대로 문자열 배열 `arr`에 저장한다.
3. 앞쪽 `(N - 1) / 2 + 1`개를 `left` 리스트에, 나머지를 `right` 리스트에 저장한다.
   - 카드 수가 짝수이면 같은 크기로 나누고, 홀수이면 왼쪽에 한 장 더 넣는다.
4. 결과 배열의 인덱스가 짝수이면 `left.get(i / 2)`, 홀수이면 `right.get(i / 2)`를 저장한다.
5. 테스트케이스 번호와 섞인 카드 순서를 출력한다.

## 작성 코드

기본 안내 주석과 주석 처리된 파일 입력 예시를 제외한 작성 코드이다.

```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;
import java.util.Scanner;
import java.io.FileInputStream;

class Solution
{
    public static void main(String args[]) throws Exception
    {
        Scanner sc = new Scanner(System.in);
        int T;
        T=sc.nextInt();

        for(int test_case = 1; test_case <= T; test_case++)
        {
            int N = sc.nextInt();
            String[] arr = new String[N];
            for(int i = 0 ; i < arr.length; i++) {
                arr[i] = sc.next();
            }
            List<String> left = new ArrayList<>();
            List<String> right = new ArrayList<>();
            String[] answer = new String[N];
            for(int i=0; i < arr.length; i++) {
                if(i < (N-1)/2+1) {
                    left.add(arr[i]);
                }else {
                    right.add(arr[i]);
                }
            }

            for(int i=0; i< arr.length; i++) {
                if(i%2==0) {
                    answer[i] = left.get(i/2);
                }else {
                    answer[i] = right.get(i/2);
                }
            }
            System.out.print("#" + test_case + " ");
            for(int i = 0 ; i< answer.length; i++) {
                if(i>0) {
                    System.out.print(" " + answer[i]);
                }else {
                    System.out.print(answer[i]);
                }
            }
            System.out.println();
        }
    }
}
```

## AI 코드 리뷰

### 개선할 점

- 양수 `N`에서 `(N - 1) / 2 + 1`은 `(N + 1) / 2`와 같다. 왼쪽 묶음의 크기를 `split` 변수로 저장하면 분할 기준을 더 쉽게 읽을 수 있다.
- `left`, `right` 리스트를 만들지 않고 원본 배열에서 직접 꺼낼 수 있다. 왼쪽 묶음의 시작 인덱스는 `0`, 오른쪽 묶음의 시작 인덱스는 `split`이다.
- 결과 순서대로 바로 `StringBuilder`에 추가하면 별도의 `answer` 배열도 생략할 수 있다.
- 카드 수가 홀수이면 왼쪽 묶음이 한 장 더 많다. 오른쪽 카드의 인덱스가 배열 길이보다 작은지 확인하면 마지막 왼쪽 카드까지 처리할 수 있다.
- `arr`를 `cards`로 바꾸면 저장한 값의 의미가 명확해진다.
- 사용하지 않는 `Arrays`, `FileInputStream` import는 제거할 수 있다.
- 작성 코드와 아래 개선 코드 모두 시간 복잡도는 `O(N)`, 카드 이름의 길이를 고정된 상한으로 볼 때 공간 복잡도도 `O(N)`이다. 개선 코드는 리스트 두 개와 결과 배열을 생략해 중간 저장 공간을 줄인다.

### AI 개선 코드

```java
import java.util.Scanner;

class Solution {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int testCount = sc.nextInt();

        for (int testCase = 1; testCase <= testCount; testCase++) {
            int size = sc.nextInt();
            String[] cards = new String[size];

            for (int i = 0; i < size; i++) {
                cards[i] = sc.next();
            }

            int split = (size + 1) / 2;
            StringBuilder output = new StringBuilder();
            output.append("#").append(testCase);

            for (int i = 0; i < split; i++) {
                output.append(' ').append(cards[i]);

                if (i + split < size) {
                    output.append(' ').append(cards[i + split]);
                }
            }

            System.out.println(output);
        }
    }
}
```
